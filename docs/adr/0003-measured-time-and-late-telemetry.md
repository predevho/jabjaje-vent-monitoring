# 시간 판단은 측정 시각 기준이고, 늦은 측정값은 지금 상태를 나타내는 이상에 쓰지 않는다

연결이 끊긴 동안 게이트웨이가 모아 둔 측정값은 다시 연결된 뒤 한꺼번에, 순서가 뒤섞여 도착한다. 그래서 모든 시간 판단은 서버가 받은 시각이 아니라 측정 시각을 기준으로 한다. 또 CO2, 풍량, 바이패스처럼 지금 상태를 나타내는 이상은 늦은 측정값으로 만들지 않는다. 몇 시간 전 데이터로 지금 이상이 생기는 것을 막기 위해서다. 반대로 `VEMC_NO_RESPONSE`처럼 시간이 지나도 의미가 남는 고장 판정에는 늦은 측정값도 쓴다.

## Consequences

- 측정값에 측정 시각과 수신 시각을 둘 다 저장하고, 늦은 측정값 여부를 표시한다.
- 이상 규칙마다 늦은 측정값을 쓰는지 여부를 정해야 한다. 규칙을 추가할 때 이 기준을 따른다.
- 끊긴 구간의 그래프는 늦은 측정값으로 채워진다.
