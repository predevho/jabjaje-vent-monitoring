# 후드 연동은 현장에서 처리하고, 서버는 감시만 한다

후드 연동을 서버가 판단해 원격 명령으로 처리하면, 인터넷이 끊겼을 때 실내 압력 균형이 깨진다. 그건 VEMC가 막으려던 바로 그 문제다. 그래서 후드 연동은 VEMC와 환기장치 사이에서 현장으로 처리하고, 서버는 후드 이벤트와 측정값을 비교해 연동이 실제로 일어났는지만 확인한다(`VEMC_NO_RESPONSE` 이상). 서버를 거치는 원격 명령은 사용자의 부스트 요청에만 쓴다.

## Considered Options

- **서버가 판단해 원격 명령으로 처리**: 로직을 서버 한 곳에서 바꿀 수 있어 편하지만, 인터넷 장애 때 안전 기능이 멈춘다. 기각.
- **현장 처리 + 서버 감시**: 채택. "안전과 관련된 제어는 현장에서, 클라우드는 감시와 편의 기능"이라는 IoT 설계 원칙과 같다.

## Consequences

- 시뮬레이터는 후드 연동을 브로커를 거치지 않고 내부에서 처리해야 한다.
- 장비는 원격 명령보다 후드 연동을 우선하고, 자기 보호 로직을 가장 먼저 따른다.
