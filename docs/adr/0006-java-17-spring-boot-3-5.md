# Java 17과 Spring Boot 3.5를 쓴다

Java 21 이상과 Spring Boot 4도 선택할 수 있었지만, Java 17과 Spring Boot 3.5를 쓴다. 현업에서 가장 많이 쓰는 LTS 조합이라 채용 후 바로 이어서 쓰기 쉽다. 21의 대표 기능인 가상 스레드는 장비 수천 대의 동시 연결이 병목이 될 때 의미가 있는데, 지금 규모에서는 필요하지 않아 오버스펙이다.

## Consequences

- 개발 PC에는 Java 25만 설치되어 있으므로, JDK 17을 따로 설치하거나 Gradle 툴체인으로 받아야 한다.
- 장비 수가 크게 늘어 동시 연결 처리가 병목이 되면 Java 21의 가상 스레드를 다시 검토한다.
